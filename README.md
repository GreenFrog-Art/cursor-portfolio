# 예술가 포트폴리오 웹사이트

Next.js와 Framer Motion을 사용하여 만든 예술적인 포트폴리오 웹사이트입니다.

## 주요 기능

- **가로 스크롤 레이아웃**: 디지털 갤러리 느낌의 유려한 가로 스크롤
- **커스텀 커서**: 마우스 커서를 따라다니는 예술적인 커스텀 커서
- **인터랙티브 이미지 효과**: 이미지 호버 시 확대 및 3D 왜곡 효과
- **부드러운 페이지 전환**: 페이드 인/아웃 애니메이션
- **타이포그래피**: 세리프체 제목과 산세리프체 본문의 조화
- **프론트엔드 작품 관리**: 브라우저에서 직접 작품 추가/편집/삭제 가능

## 섹션 구성

1. **Intro**: 전체 화면 슬로건과 배경 그라데이션
2. **Work Gallery**: 비정형 그리드 레이아웃의 작품 갤러리
3. **About**: 텍스트 중심의 소개 페이지

## 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

### 빌드

```bash
npm run build
npm start
```

## 커스터마이징

### 작품 이미지 추가 (프론트엔드에서)

1. 웹사이트 우측 하단의 관리자 패널 버튼(점 3개 아이콘)을 클릭하세요
2. "작품 추가" 버튼을 클릭하여 새 작품을 추가하세요
3. 이미지는 다음 방법으로 추가할 수 있습니다:
   - **파일 업로드**: 
     - 이미지 파일을 선택하거나 드래그 앤 드롭으로 업로드
     - 최대 10MB (JPG, PNG, GIF, WebP 지원)
     - 서버의 `public/uploads` 폴더에 실제 파일로 저장됩니다
     - 업로드 진행 상태가 실시간으로 표시됩니다
   - **URL 입력**: 외부 이미지 URL을 직접 입력
4. 제목, 카테고리, 이미지 크기를 입력하고 저장하세요

**주요 기능**:
- ✅ **드래그 앤 드롭**: 이미지 파일을 드래그하여 업로드 영역에 놓으면 자동 업로드
- ✅ **실시간 업로드 진행률**: 업로드 중 진행 상태 표시
- ✅ **자동 이미지 크기 감지**: 업로드된 이미지의 너비/높이 자동 감지
- ✅ **에러 처리**: 명확한 에러 메시지 표시
- ✅ **미리보기**: 업로드 전 이미지 미리보기

**참고**: 
- 업로드한 이미지는 `public/uploads` 폴더에 저장됩니다
- 작품 메타데이터는 브라우저의 로컬 스토리지에 저장됩니다
- 작품 수정/삭제는 관리자 패널에서 가능합니다
- "초기화" 버튼으로 기본 샘플 작품으로 되돌릴 수 있습니다

### 배경 영상 추가

`app/components/IntroSection.tsx`에서 주석 처리된 비디오 태그를 활성화하고 `public` 폴더에 비디오 파일을 추가하세요.

### 폰트 변경

`app/layout.tsx`에서 Google Fonts를 변경하거나 다른 폰트를 추가할 수 있습니다.
